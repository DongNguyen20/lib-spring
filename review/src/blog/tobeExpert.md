## 1. Java Chuyên Sâu

- Java 17 trở lên, hiểu rõ syntax, memory, exception
- OOP nâng cao, Design Patterns (SOLID, GOF)
- Generics, Reflection, Annotations
- JVM Internals (GC, JIT, Classloader)
- Java Memory Model
- Java Performance tuning
- Concurrency: `synchronized`, `ReentrantLock`, `CompletableFuture`, `ExecutorService`

---

## 2. Spring & Hệ sinh thái

- **Spring Core**: IoC, DI, Bean Lifecycle
- **Spring Boot**: AutoConfig, Profiles, Actuator
- **Spring MVC / WebFlux**
- **Spring Data JPA**: Repository, QueryDSL
- **Spring Security**: Basic, JWT, OAuth2, Method Security
- **Spring AOP**
- **Spring Cloud**:
    - Config Server
    - Eureka / Consul
    - API Gateway (Spring Cloud Gateway)
    - Circuit Breaker (Resilience4j)
    - Feign Client
- **Spring Batch**
- **Spring Kafka**, **Spring AMQP**

---

## 3. Thiết kế Hệ thống & Kiến trúc

- Clean Architecture, Hexagonal Architecture
- RESTful API Design
- API Versioning, Pagination, HATEOAS
- Event-driven Architecture
- CQRS, SAGA Pattern
- Domain-Driven Design (DDD)
- Monolith → Microservices transition
- Caching (Redis, CDN)
- Rate Limiting, Throttling
- Load Balancer, API Gateway (Nginx, Kong)

---

## 4. Hiệu năng & Tối ưu

- JVM Tuning: Heap, GC strategy
- Profiling: VisualVM, JFR, JMC
- Database Indexing, Explain Plan
- Connection Pool (HikariCP tuning)
- Asynchronous programming
- Non-blocking IO (WebFlux / Netty)
- Bulkhead, Retry, Timeout, CircuitBreaker (Resilience4j)

---

## 5. Bảo mật nâng cao

- HTTPS, TLS, CSRF, CORS
- OAuth2 & OpenID Connect (Keycloak, Auth0)
- JWT best practices (expiry, rotation)
- API Gateway security filters
- Security headers (CSP, XSS-Protection)
- Secrets Management (Vault, AWS Secrets Manager)
- Logging Sensitive Data handling

---

## 6. Microservices & Event-Driven

- Microservice communication:
    - REST
    - gRPC
    - Message Queue (RabbitMQ, Kafka)
- Kafka internals: topic, partition, consumer group
- Schema Registry, Avro/Protobuf
- Idempotency, Outbox Pattern
- Distributed Tracing (Zipkin, Sleuth)

## 7. CI/CD & DevOps

- Git, GitHub/GitLab workflow
- Jenkins / GitHub Actions / GitLab CI
- Docker (multi-stage build, volumes, networks)
- Docker Compose
- Kubernetes: pod, service, ingress, HPA, configMap
- Helm Charts, ArgoCD
- SonarQube, Checkstyle
- Test automation: Unit, Integration, Contract tests

## 8. Cloud Platform

- AWS (EC2, S3, RDS, IAM, ECS, Lambda)
- Azure, GCP (tuỳ định hướng)
- Terraform / Pulumi
- Load Balancer, CloudWatch / CloudTrail
- Serverless patterns
- Deploy multi-region, high-availability setups

## 9. Soft Skills & Leadership

- Communication: viết giải pháp rõ ràng
- Code review mindset
- Mentoring junior devs
- Task estimation & deadline management
- Document Architecture & APIs (ADR, PlantUML)
- Tư duy sản phẩm: hiểu người dùng, nghiệp vụ
